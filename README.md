🧮 BMI Calculator
A simple and responsive BMI Calculator web application that computes your Body Mass Index (BMI) based on age, height, and weight. The app categorizes the result and displays it with a dynamic visual indicator bar. Built with HTML, CSS, and JavaScript.

🚀 Features
📥 Input fields for age, height (cm), and weight (kg)

🧠 Real-time BMI calculation and category display

🎨 Stylish and responsive UI with a gradient background

📊 Dynamic BMI indicator bar for easy visual interpretation

🔁 Reset button to clear inputs and results

🚨 Input validation to ensure positive values

💡 BMI Categories
Underweight: BMI < 18.5

Normal weight: 18.5 ≤ BMI < 24.9

Overweight: 25 ≤ BMI < 29.9

Obesity: BMI ≥ 30

🛠️ Built With
HTML5

CSS3 (including media queries and gradient styles)

JavaScript (DOM manipulation and input validation)
